# Vorlage: Change Request (Änderungsantrag)

> Entspricht `ChangeRequest.docx` aus den Vorlesungsunterlagen.

```markdown
# [TEAM#Issue-ID]: [Titel der Änderung]

- **Kennung:** `TEAM#Issue-ID` (z. B. `coding#45`)
- **Datum:** [YYYY-MM-DD]
- **Antragsteller:** [Name, Team]
- **Betroffene Teams:** [Team A, Team B]

---

### Betroffene Anforderungen & Schnittstellen
- **Anforderungen:** `coding#12`
- **Schnittstellen:** `assets#34`

### Bisheriger Stand
[Kurze Beschreibung der bisher getroffenen Vereinbarung oder Implementierung]

### Gewünschte Änderung
[Was genau soll geändert, hinzugefügt oder gestrichen werden?]

### Begründung
[Warum ist die Änderung notwendig? z. B. neue technische Erkenntnisse, Aufwand, Feedback]

### Auswirkungen
- **Auf das Produkt / Gameplay:** [Funktionale Auswirkungen]
- **Auf Termine:** [Verzögerung oder Vorverlegung von Meilensteinen]
- **Auf andere Arbeitspakete:** [Mehraufwand für Nachbarteams]

---

### Entscheidung
- **Status:**
  - [ ] angenommen
  - [ ] abgelehnt
  - [ ] zurückgestellt
  - [ ] weitere Klärung erforderlich
- **Beschlussdatum:** [Datum]
- **Entscheider / beteiligte Teams:** [Namen der Beteiligten]

### Umsetzung
- **Neuer Anforderungsstand:** [Version, z. B. 1.1]
- **Betroffene Dokumente:** [Liste der angepassten Dateien und Issues]
```
