# Vorlage: Wöchentliches Team-Update

> Für das wöchentliche Statusupdate an das RI-Team (ab 30.10.2026).

```markdown
# Wöchentliches Update: [Teamname]

- **Datum:** [YYYY-MM-DD]
- **Sprint / Berichtszeitraum:** [z. B. SPRINT-2 / KW 44]
- **Verantwortliche Ansprechperson:** [Name]

### 1. Gesamtstatus
- [ ] 🟢 **stabil** (im Zeitplan, keine wesentlichen Hindernisse)
- [ ] 🟡 **Risiken / Klärungen** (Klärungsbedarf vorhanden, bremst leicht)
- [ ] 🔴 **relevante Blocker** (Arbeit stockt, externe Hilfe nötig)

### 2. Fortschritt im aktuellen Sprint
- **Erledigte GitHub Issues:** `#10`, `#14`
- **Aktuell in Arbeit:** `#15`, `#16`

### 3. Änderungen an Anforderungen seit letzter Woche
| Issue | Art der Änderung | Begründung | Betrifft Nachbarteams? |
| :--- | :--- | :--- | :--- |
| `#12` | neu / angepasst / verworfen | [Begründung, z. B. technische Limitierung] | Nein / Ja ([Team]) |

### 4. Schnittstellen (neu, geändert oder abgestimmt)
- [ ] Keine Änderungen
- Falls ja: Bezug auf Vereinbarung (z. B. `builder#5`)

### 5. Blocker & Risiken
- [ ] Keine aktuellen Blocker
- Falls vorhanden: [Genaue Beschreibung, welches Team oder welche Entscheidung
  blockiert]

### 6. Geplante Aufgaben bis nächste Woche
- [Aufgabe 1 mit Issue-Ref]
- [Aufgabe 2 mit Issue-Ref]
```
