# Backups

Um Datenverlusten vorzubeugen, muss die Minecraft-Welt regelmäßig gesichert werden.
Da für den Docker-Container ein sog. Bind-Mount verwendet wurde, kann die Welt direkt aus dem Ordner
`/data/worlds/level/` exportiert werden. Dort befinden sich die "rohen" Spieldateien:

### Komprimierung

```
root@ubuntu:/opt/minecraft# ls data/worlds/level/
db  level.dat  level.dat_old  levelname.txt
```

Um nun ein komprimiertes Archiv aus diesen Dateien zu erstellen musste folgendes bedacht werden:

- Die Komprimierung muss eine sinnvolle Balance zwischem dem Komprimierungsfaktor und der Compute-Effizienz der Operation treffen.
- Ein bereits in Linux integriertes Tool zum Komprimieren ist bevorzugt
- Das Archiv muss, falls es größer als 2GiB ist, in mehrere Dateien aufgespaltet werden, da die Welt auf Github gesichert werden soll. Ein Angang darf dort maximal 2GiB groß sein.

Die Entscheidung fiel aufgrund dieser Faktoren auf `tar` / `zst`:
`sudo apt update && sudo apt install -y zstd`

Dies ist der verwendete Befehl um ein Backup zu erstellen:
`tar -cf - data/worlds/level | zstd -19 -T0 | split -b 2G -d - some_minecraft_backup.tar.zst.`

`tar -cf` bündelt die Inhalte des Ordners in einen einzigen gebündelten Stream

`zstd -19 -T0` komprimiert diesen so stark wie möglich unter Verwendung aller verfügbaren CPU-Threads

`split -b 2G` teilt das resultierende komprimierte Archiv ggfs. in Einzelteile auf

### Sicherung

Die entstandenen `.tar.zst` Dateien können dann gesichert werden.
Hier wurden diese versioniert und auf Github als _Release_ publiziert:

`gh release create v0.0.1 --title "Minecraft World v0.0.1" /opt/minecraft/some_minecraft_backup.tar.zst.*`

### Restore

Um ein Backup wiederherzustellen werden die folgenden Schritte durchgeführt:

Erst wird der Server gestoppt

```
root@ubuntu:/opt/minecraft# docker compose down
[+] down 2/2
 ✔ Container minecraft-bedrock-server Removed                                                                                    0.7s
 ✔ Network minecraft_bedrock-net      Removed
```

Im Anschluss wird der existierende Inhalt des `level` Ordners geleert

```
root@ubuntu:/opt/minecraft# rm -rf data/worlds/level/*
root@ubuntu:/opt/minecraft# ls data/worlds/level/
```

Dann kann das Archiv in diesen Ordner entpackt, und der Server wieder gestartet werden

```
root@ubuntu:/opt/minecraft# cat a_minecraft_backup.tar.zst.* | tar -I zstd -xf - -C /opt/minecraft/
root@ubuntu:/opt/minecraft# ls data/worlds/level/
db  level.dat  level.dat_old  levelname.txt
root@ubuntu:/opt/minecraft# docker compose up -d
[+] up 2/2
 ✔ Network minecraft_bedrock-net      Created                                                                                    0.0s
 ✔ Container minecraft-bedrock-server Started                                                                                    0.3s
```
