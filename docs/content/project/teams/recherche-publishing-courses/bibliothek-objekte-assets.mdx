## Recherche-Zusammenfassung

### 1. Studiengänge an der DHSN (Anzahl: 5 Bücherregale)
Für die Library-Quest werden 5 Regale bzw. Fächer benötigt, basierend auf den Kernstudiengängen der DHSN Leipzig:
1. **Informatik**
2. **Steuerberatung / Tax Advice**
3. **Nachhaltige Ingenieurwissenschaften (Sustainable Engineering)**
4. **Controlling & Finance**
5. **Immobilienwirtschaft (Real Estate)**

### 3. Technische Umsetzung für Item-Beschreibungen (Minecraft Bedrock)

#### Umsetzungsmöglichkeiten:
1. **Custom Item Definition (`format_version: "1.20.80"`):**
   * Über die Komponente `minecraft:display_name` (inkl. Zeilenumbruch `\n`) und `minecraft:hover_text_color` lässt sich der Tooltip direkt im Item-JSON hinterlegen:
     ```json
     {
       "format_version": "1.20.80",
       "minecraft:item": {
         "description": {
           "identifier": "dhsn:book_cs",
           "category": "items"
         },
         "components": {
           "minecraft:hover_text_color": "aqua",
           "minecraft:display_name": {
             "value": "Data Analytics & Python\n§7Enthält Grundlagen zu Algorithmen, Datenstrukturen und Python-Skripten."
           }
         }
       }
     }
     ```
2. **Bedrock Script API (`@minecraft/server`):**
   * Dynamisches Setzen der mehrzeiligen Item-Lore per Skript über `ItemStack.setLore()`:
     ```javascript
     import { ItemStack } from "@minecraft/server";

     const item = new ItemStack("minecraft:book", 1);
     item.nameTag = "§9Data Analytics & Python";
     item.setLore([
       "§7Enthält Grundlagen zu Algorithmen,",
       "§7Datenstrukturen und Python-Skripten."
     ]);
     ```

#### Textlängen-Guideline:
* Max. 2 bis 3 Zeilen Text, damit das Tooltip-Fenster im Inventar nicht den Bildschirmrand überragt.
* Bedrock-Farbcodes (`§7` für Grau/Standard-Lore, Farbcodes passend zum Studiengang) nutzen.
