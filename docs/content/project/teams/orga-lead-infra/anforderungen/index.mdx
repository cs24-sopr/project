## 1. Zweck und Ziel

Das Arbeitspaket Organisation und Infrastruktur stellt die technische
Plattform (Entwicklungsserver, AddOn-Packaging, CI/CD) sowie die
organisatorischen Werkzeuge (Board, Vorlagen, RI-Register) für alle
Projektteams bereit.

- **Output:** Automatisierte Export-Pipeline für das herunterladbare
  Minecraft Bedrock AddOn / Welt-Template, stabiler Entwicklungs-Server für
  den Bau, Docusaurus-Dokumentation, gepflegtes Project Board.
- **Outcome:** Studieninteressierte können das AddOn selbst herunterladen und
  lokal spielen; alle Teams können parallel ohne Datenverlust zusammenarbeiten.
- **Benefit:** Gewährleistung der Projektergebnisse für die DHSN Leipzig.

## 2. Produkt- und Arbeitspaketbeschreibung

Bereitstellung von Entwicklungs- und Testumgebungen für den virtuellen
Nachbau der DHSN Leipzig, Sicherstellung des Datenbestands sowie Übernahme der
Querschnittsaufgabe Requirements and Integration (RI).

## 3. Scope

### In Scope

- Server-Setup und Konfiguration (Bedrock Dedicated Server als
  Entwicklungsumgebung)
- Packaging- und Export-Pipeline für das finale Bedrock AddOn zum Herunterladen
- Automatische World-Backups und Exporte zu GitHub Releases
- Docusaurus-Plattform im GitHub Repository mit GitHub Pages Deployment
- Standardisierte Issue-Templates und GitHub Project Board Konfiguration
- Team- und Gesamtprojektkalender für agiles Arbeiten
- RI-Gesamtübersicht und wöchentliches Reporting an die Betreuerin

### Out of Scope

- Erstellung spielinhaltlicher Modelle, Gebäude und Quests.
- Direkte Implementierung von Skripten oder Gameloops (Aufgabe Coding).

## 11. Abnahmekriterien

- Der Bedrock-Server läuft stabil und ist für berechtigte Personen erreichbar.
- Welt-Backups werden automatisiert exportiert und als Release bereitgestellt.
- Docusaurus wird bei Commits auf `main` automatisch gebaut und publiziert.
- Project Board, Kalender und Vorlagen sind vollständig einsatzbereit.
- Das wöchentliche Reporting an die Betreuerin startet fristgerecht
  zum 30.10.2026.
