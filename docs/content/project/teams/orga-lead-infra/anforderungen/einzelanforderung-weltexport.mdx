### Anforderung
Das System muss einmal täglich automatisch ein komprimiertes Archiv des
aktuellen Weltenordners `/data/worlds/level/` erstellen und dieses als
GitHub Release unter Verwendung eines Datums-Tags hochladen.

### Begründung / Quelle
Das Bauteam und das Coding-Team arbeiten kontinuierlich auf dem Server. Ohne
automatisierte, versionierte Backups führen Fehlkonfigurationen oder
Zerstörungen zu unwiederbringlichem Datenverlust. GitHub Releases bieten
einen transparenten Download für alle Teammitglieder.
