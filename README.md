## 📋 Issue Workflow

We use a structured **WHAT-HOW-TEST** format for all tasks, bugs, and feature requests.

### Creating an Issue
1. Go to the **Issues** tab and click **New issue**.
2. Select the **Task / Feature** template.
3. Fill out the three sections:
   - **WHAT**: Goal, requirements, and problem description.
   - **HOW**: Technical implementation plan (affected files, APIs, architecture).
   - **TEST / Expected Behavior**: Acceptance criteria and verification steps.
4. Click **Submit new issue** (the issue number is assigned automatically).
